# RakCRMP Helper

Telegram-бот для заказов на мониторинг игрового маркета Black Russia. Выбираешь сервер и существующий аккаунт уровня 3+, вводишь название предмета, границы цены от 0 до 100 000 000 ₽ и интервал от 5 до 60 секунд. Режим уведомлений присылает новые совпадения. Автопокупка берёт по одной штуке подходящего лота после сверки карточки. В «Мои заказы» доступны статус, число уникальных совпадений, подтверждённые покупки и кнопка остановки.

## Запуск Telegram-бота

Для управляющего процесса нужны Python 3.12, PostgreSQL, OpenSSH Client и публичный HTTPS-адрес. Один экземпляр процесса одновременно ведёт Telegram, формы и очередь. Создай отдельную роль и базу PostgreSQL. Роли потребуется право создавать таблицы и индексы в этой базе.

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
chmod 600 .env
```

Заполни `BOT_TOKEN`, `ADMIN_ID`, `DATABASE_URL` и `PUBLIC_WORKER_URL` в `.env`. В последний впиши публичный HTTPS-адрес без пути. Из настроек PostgreSQL достаточно `DATABASE_URL`.

Бот сам создаёт ключ шифрования игровых паролей в `data/game-passwords.key` (на Bothost — `/app/data/game-passwords.key`). При переносе управляющего сервиса сохрани этот файл вместе с данными. Для другого каталога задай `DATA_DIR`.

Если в старой установке уже задан `DATABASE_KEY`, оставь его на первом запуске обновления. Бот перенесёт действующий ключ в файл. После успешного запуска переменную можно удалить.

```bash
set -a
. ./.env
set +a
python -m helper.control
```

Проксируй HTTPS к `127.0.0.1:8080`. Например, для Caddy:

```caddyfile
helper.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

Не записывай тела запросов и адреса одноразовых форм в журнал внешнего прокси. `GET /health` можно использовать для проверки, что сервис поднялся. PostgreSQL доступен управляющему процессу. На VPS воркера нужен исходящий HTTPS к панели и доступ к игровому серверу.

## Установка воркера на VPS

1. Открой личный чат с ботом, отправь `/admin` и нажми **Установить на VPS**.
2. В одноразовой форме введи публичный IP VPS, SSH-логин, пароль и проверенный SHA256-отпечаток SSH-ключа. Посмотреть отпечаток можно из панели провайдера или уже доверенной консоли VPS:
   ```bash
   ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256
   ```
3. Установщик использует SSH на порту 22. Поддерживается Linux с systemd, системным `/usr/bin/python3` версии 3.10+ и входом через `root` или пользователя с `sudo -n`. Воркер ставится в `/opt/rakcrmp-helper-worker` и запускается как `rakcrmp-helper-worker.service`. Запущенный воркер установщик не заменяет.
4. После установки открой `/admin` и проверь, что VPS в сети. Лог сервиса доступен через `journalctl -u rakcrmp-helper-worker`.

Пароли вводятся в одноразовых формах. Пароль игры шифруется до выдачи заказа и удаляется из очереди при выдаче воркеру. Воркер получает свой HTTPS-токен и выполняет один заказ за раз. Токен Telegram и доступ к PostgreSQL остаются у управляющего процесса. Пароль SSH используется на время установки.

## Как работает заказ

Воркер входит в существующий аккаунт, открывает планшет, проверяет уровень и доступность маркета. Маркет всегда открывается с сортировкой по возрастанию. Очередь не допускает одновременных заказов на один и тот же аккаунт и сервер. После остановки VPS закрывает сессию. Если покупка уже отправилась, сервер может закончить её до отключения.

Покупка засчитывается только после подтверждения игры. Если ответ потерялся, заказ останавливается с неопределённым результатом. Повторной покупки такого лота по этому заказу не будет. После покупки игра требует забрать предмет в пункте выдачи.

Текущая версия обрабатывает **первую страницу** и группу лотов `tp=0`, для которой запись подтвердила покупку за рубли. Карточка заказа показывает, если поисковая выдача длиннее. Если сервер запросит капчу или дополнительный шаг входа, заказ заканчивается с ошибкой. Интервал проверок относится к началу очередного поиска. Долгий запрос или проверка карточки может удлинить цикл.

Транспорт в `runtime/` выделен из [RakCRMP](https://github.com/creepyside11/black/tree/f1efdfed0fd38e2e70e833de06ac0a19b9c80f19). В пакете воркера только игровой транспорт и обработчик заказа.

## Проверки

```bash
pip install httpx
python -m unittest discover -s tests -v
```

Для теста очереди задай `TEST_DATABASE_URL` отдельной тестовой базы. Тест очищает таблицы Helper в этой базе. Тестовый сценарий эмулирует игровые ответы по записи. Перед реальным запуском проверь вход и уведомления на разрешённом тестовом аккаунте.

## Mini App на Bothost

Домен для этой сборки — `rakcrmphelper.bothost.tech`. Проект запускает Telegram polling, Mini App и очередь воркеров одним процессом.

1. Подключи репозиторий `creepyside11/br-helpers-sell`, ветку `main`. Включи **Использовать собственный Dockerfile**. Он устанавливает SSH-клиент для кнопки **Установить на VPS**.
2. В панели привяжи домен `rakcrmphelper.bothost.tech` и выставь внутренний порт **3000**. Приложение слушает `0.0.0.0` и читает `PORT` из окружения.
3. Добавь `BOT_TOKEN`, `ADMIN_ID` и `DATABASE_URL`. Значения для домена и порта приведены в [.bothost.env.example](.bothost.env.example). Ключ шифрования бот хранит в постоянной папке `/app/data`. При обновлении старой установки перенеси прежний `DATABASE_KEY` по инструкции выше.
4. Разверни проект. Проверка сервиса доступна по адресу `https://rakcrmphelper.bothost.tech/health`.
5. В личном чате с ботом открой меню **Маркет** или отправь `/start` и нажми **Открыть Mini App**. Заказы в приложении и чате общие. Если Telegram требует привязать домен к боту, добавь публичный URL в настройках Menu Button в BotFather.

Каждые 5 минут 30 секунд между проверками воркер может пройти короткий отрезок пешком и вернуться. На время движения он закрывает маркет, затем открывает его и снова включает сортировку по возрастанию. Если персонаж в транспорте, движения не будет. Поведение на живом сервере требует отдельной проверки.

Старый воркер не обновляется при пересборке Bothost. Если он уже установлен, останови его после завершения активного заказа (`sudo systemctl stop rakcrmp-helper-worker`), затем снова запусти установку через `/admin`. Установщик зарегистрирует воркер под текущим доменом панели.
